## Hike images

Each hike has its own sub-folder in this directory.

- Add trail photos into the matching hike folder (example: `01-bessies-loop`).
- The site auto-loads trail photos from these folders, so you usually do **not** need to edit `index.html` to attach images.
- Preferred web-display formats: JPG, JPEG, PNG, WebP, GIF, or AVIF.
- If you upload HEIC files to `main`, a GitHub Action automatically creates JPEG versions in the same folder for browser compatibility.
